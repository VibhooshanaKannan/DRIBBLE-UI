Welcome to the Dribbble UI Replica, a frontend-only project that replicates the modern and interactive design of Dribbble.com using the power of Next.js, custom styling, and smooth animations. 

 Features Implemented
      Responsive Navbar with dropdown menus and search
      Footer with multiple link groups and social icons
      Component-based UI design (reusable and clean)
      Fintech App Design Showcase Page
      For Designers Landing Page
      Hire Talent Page
      Inspiration Gallery Page
      Careers Info Page
      Smooth animations using CSS transitions and keyframes
      Fully styled with consistent color palette and layout

Tech Stack & Tools Used
Tool	
Next.js	- React-based framework for SSR & routing
React Icons	- Icon library used for UI elements
CSS Modules / Custom CSS	- For complete control over styling and layout
VS Code	- Code editor of choice


**HOW TO RUN?
 Clone the Repository : 
       git clone https://github.com/VibhooshanaKannan/dribble-ui.git
       cd dribble-ui
 Install Dependencies
       npm install
 Run the Dev Server
       npm run dev
